SECTION 00

개요

Claude Code를 사용하기 전에 알아야 할 기본 원칙입니다.

Claude Code는 작업을 돕는 도구입니다.

파일을 읽고, 코드를 작성하거나 수정할 수 있습니다. 그러나 답변과 결과가 항상 정확한 것은 아닙니다. 작업의 목표와 최종 판단은 사용자에게 있습니다.

빠른 시작 4단계

STEP 1 · 02설치개인 PC에 VS Code와 Claude Code 설치
STEP 2 · 04~05폴더 열기연습용 폴더를 VS Code로 열기
STEP 3 · 06CLAUDE.md기본 규칙 몇 줄 작성
STEP 4 · 08첫 지시4구조로 요청하고 결과 검증

처음이라면 00~09를 순서대로 보시고, 10(심화)은 기본에 익숙해진 뒤 필요할 때 참고하세요. 설치와 실습은 개인 PC의 연습용 폴더에서만 진행합니다.

사용 전 확인 사항

01기본 개념 이해

폴더·파일·확장자, 입력·출력의 차이를 알면 작업 내용을 확인하기 쉽습니다. 코드를 모두 외울 필요는 없습니다.

02업무 지식 확보

데이터의 의미, 작업 목적, 정상 조건은 해당 분야를 아는 사람이 정해야 합니다. AI가 모든 업무 맥락을 자동으로 아는 것은 아닙니다.

03작은 단위로 진행

한 번에 많은 변경을 요청하기보다 단계별로 진행하세요. 변경 전후의 파일과 실행 결과를 비교하면 오류를 찾기 쉽습니다.

04결과 직접 검증

AI가 작성한 코드와 설명에는 오류가 있을 수 있습니다. 테스트 결과와 실제 파일 변경 내용을 확인한 뒤 사용하세요.

오류 발생 시 기본 확인 순서

오류가 발생하면 다음 항목을 확인합니다. 원인을 파악하지 않은 상태에서 같은 명령을 반복하지 마세요.

1
오류 메시지 확인

어떤 단계에서 실패했는지, 메시지에 어떤 파일명과 경로가 표시되는지 확인합니다.

2
입력·파일·환경 확인

파일이 존재하는지, 저장 위치와 이름이 맞는지, 필요한 프로그램이 설치돼 있는지 확인합니다.

3
공식 문서 확인

명령어나 설정에 문제가 있다면 해당 프로그램의 공식 문서와 문제 해결 안내를 확인합니다.

4
한 가지씩 수정·재확인

원인 후보를 하나씩 변경하고 같은 조건에서 다시 확인합니다. 해결 과정과 결과를 기록하면 재발 대응에 도움이 됩니다.

보안 및 승인실제 업무 데이터·계정 정보·내부 문서를 외부 서비스에 임의로 입력하지 마세요. 회사 PC에서는 승인된 도구와 사내 보안 규정을 따르세요.
핵심 원칙 목표는 사람이 정의하고, AI의 작업은 사람이 검증합니다.

이런 작업에 활용할 수 있습니다

아래는 개인 PC의 연습용 파일을 기준으로 한 예시입니다. 실제 업무 데이터는 사용하지 마세요.

A데이터 정리

CSV·엑셀 파일의 중복 행 제거, 날짜·단위 형식 통일, 열 이름 정리처럼 손이 많이 가는 정리 작업.

예) “sample.csv의 날짜 열을 YYYY-MM-DD로 통일한 새 파일을 만들어 줘”

B문서 정리

여러 문서의 제목·양식 통일, 긴 문서 요약, 오탈자와 표현 점검.

예) “docs 폴더 문서들의 제목 형식을 통일할 계획부터 알려 줘”

C반복 작업 자동화

파일 이름 일괄 변경, 폴더 정리, 데이터 변환 같은 반복 작업을 스크립트로 작성하고 실행.

예) “폴더의 파일명을 날짜_이름 형식으로 바꾸는 스크립트를 만들어 줘”

D오류 원인 분석

오류 메시지나 로그 파일을 읽고 원인 후보와 확인 순서를 정리.

예) “error.log를 읽고 원인 후보를 가능성 순으로 정리해 줘”

주의Claude Code가 제안한 파일 수정·명령 실행은 내용을 확인한 뒤 승인하세요. 자동 실행은 결과가 정확하다는 뜻이 아닙니다.
확인 포인트 설명하는 AI와 작업하는 AI의 차이를 이해하면 됩니다.

10-4서브에이전트일부 작업을 나눠 맡기는 실행 단위

각 에이전트의 결과가 주요 대화로 돌아옵니다.

Claude가 필요하다고 판단하면 기본 내장 서브에이전트를 자동으로 호출할 수도 있습니다.

서브에이전트

Claude Code 입력창 (지시문)
현재 프로젝트의 .claude/agents/ 폴더에
document-reviewer 서브에이전트를 만들어 주세요.

도구 호출 기록과 결과를 확인합니다. 새 agents 폴더가 인식되지 않으면 Claude Code를 다시 실행합니다.

10-5Hook정해진 시점에 명령을 자동 실행

Hook은 정해진 시점에 미리 등록한 명령을 자동 실행하는 기능입니다.

Hook의 동작 방식

Claude Code 작업파일 읽기·수정 등
→
설정한 시점 발생예: 파일 수정 완료
→
Hook 자동 실행사전에 등록한 명령
→
작업 진행결과 또는 차단 여부 확인
CLAUDE.md

Claude에게 작업 규칙을 알려주는 문서입니다.

Hook

특정 이벤트가 발생하면 등록된 작업을 실행합니다.

대표적인 실행 시점

PreToolUse도구 사용 직전
PostToolUse도구 사용 성공 후
Notification사용자 알림 발생 시
StopClaude의 응답 종료 시도 시

설정 및 확인 방법

01

설정 파일 확인

VS Code에서 현재 폴더의 .claude 폴더를 엽니다. 그 안의 settings.json 파일이 프로젝트 설정 파일입니다.

프로젝트 폴더 안의 파일 경로
.claude/settings.json

파일이 없다면 새 파일을 만들 수 있습니다. 기존 설정 파일이 있다면 내용을 지우지 마세요.

02

Hook 설정 내용 이해

다음은 파일 편집 도구가 실행된 뒤 문구를 출력하는 기초 예시입니다. 동작을 이해하기 위한 예시이며, 외부 프로그램은 실행하지 않습니다.

settings.json 작성 예시
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "echo Hook executed"
          }
        ]
      }
    ]
  }
}

settings.json은 JSON 형식입니다. 괄호·쉼표가 잘못되면 설정 오류가 발생할 수 있습니다.

03

등록 여부 확인

Claude Code 입력창에서 아래 명령어를 실행하면 등록된 Hook을 확인할 수 있습니다.

Claude Code 입력창
/hooks
실행 주의Hook에 등록된 명령은 조건이 맞으면 자동 실행됩니다. 출처가 불분명한 Hook이나 스크립트는 실행하지 마세요. 사내 PC에서는 승인되지 않은 Hook을 등록하지 마세요.

참고: Claude Code 공식 Hook 안내

확인 포인트 Hook은 ‘명령을 내릴 때마다 무조건 실행’이 아니라, 설정된 이벤트에 따라 실행됩니다.
